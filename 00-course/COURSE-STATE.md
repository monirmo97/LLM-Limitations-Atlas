## Stage 0 objective

Build the mental framework needed before historical and limitation-specific papers:

1. understand the LLM system at a high level;
2. understand where limitations can arise in the lifecycle;
3. distinguish model, interaction, system, safety, and evaluation limitations;
4. understand how evidence supports or fails to support a limitation claim.

## Next exact lesson

### Stage 0 — Lesson 1: The LLM system map

Start by constructing this mental pipeline:

```text
Data
 -> Pretraining
 -> Base model
 -> Post-training / alignment
 -> Inference
 -> Prompt + context
 -> Optional retrieval/tools/agents
 -> Output/action
 -> Evaluation
```

For each point, answer:

- What happens here?
- What kind of limitation can originate here?
- How can a failure at this point be confused with a failure somewhere else?

The learner should finish Lesson 1 able to draw this pipeline from memory and name several places where limitations can arise.

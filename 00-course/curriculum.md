# Curriculum

## Learning objective

Develop a structured mental model of LLM limitations and the evidence behind them. The learner should be able to connect observed failures to the LLM lifecycle, evaluate limitation claims scientifically, explain conflicting evidence, and analyze new papers independently.

## Fixed teaching backbone

The official course sequence is:

`Stage 0 -> Stage 1 -> Stage 2 -> Stage 3 -> Stage 4 -> Stage 5 -> Stage 6`

Required topics are minimum coverage. New subtopics may be added when the literature requires them, but required topics are not removed and stages are not skipped.

### Stage 0 — Mental framework

- How LLMs work
- Where limitations can arise
- How limitation claims are evaluated

### Stage 1 — Historical foundations

- 2020
- 2021
- 2022
- Emergence of modern LLMs and modern limitation research

### Stage 2 — Core behavioral limitations

- Reasoning
- Generalization
- Hallucination / factuality
- Calibration / uncertainty
- Context & memory
- Grounding / causal understanding

### Stage 3 — Interaction + learning/control

- Prompt sensitivity
- Multilingual / cultural
- Multimodal
- Alignment / controllability
- Knowledge editing
- Forgetting / unlearning

### Stage 4 — Systems + safety

- Agents / planning
- RAG / tool use
- Bias / fairness
- Security / jailbreaks
- Privacy / memorization
- Efficiency / cost

### Stage 5 — Evaluation

- Benchmark contamination
- Benchmark validity
- Shortcut success
- LLM judges
- Evaluation reliability

### Stage 6 — Integrated synthesis

- What was fixed?
- What persists?
- What is disputed?
- What might be fundamental?
- What remains unknown?

## Parallel literature layer

Across all stages, maintain a 2020–2026 evidence layer containing, when available:

- foundational papers;
- strong empirical demonstrations;
- replications/extensions;
- counter-evidence or qualifications;
- modern-model reassessments;
- mitigation papers;
- 2025–2026 frontier work.

The literature census is broad and reproducible. The deep-read set contains the papers needed for a defensible mental model; it is not required to deeply read every paper in the census.

## Topic study pattern

For each important limitation/topic:

1. definition, map, and boundaries;
2. historical timeline;
3. foundational paper(s);
4. strongest empirical evidence;
5. replication/extension;
6. strongest counter-evidence or qualification;
7. modern-model reassessment;
8. 2025–2026 frontier evidence;
9. synthesis;
10. recall / teach-back.

## Completion rule

A lesson is not complete because material was shown. It is complete only after the learner participates, demonstrates understanding, connects the new node to the knowledge graph, and the durable scientific summary is saved.

A stage is complete only after its required concepts and evidence are covered, the stage graph is updated, a synthesis exists, and the learner can reconstruct and explain the stage from memory.

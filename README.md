# LLM Limitations Atlas

An evidence-first atlas of Large Language Model (LLM) limitations from 2020–2026.

## Goals

- Build a structured literature census of LLM limitation research.
- Study important papers deeply with reproducible notes.
- Build a mental model of what LLMs can do, where they fail, and what evidence supports each claim.

## Study rule

A failure observed in an experiment is not automatically a universal limitation. Every claim must record:

- What the evidence proves.
- What it does not prove.
- Experimental weaknesses.
- Later supporting or contradicting work.

## Official course architecture

The teaching backbone is fixed and sequential:

`Stage 0 -> Stage 1 -> Stage 2 -> Stage 3 -> Stage 4 -> Stage 5 -> Stage 6`

- Stage 0 — Mental framework
- Stage 1 — Historical foundations
- Stage 2 — Core behavioral limitations
- Stage 3 — Interaction + learning/control
- Stage 4 — Systems + safety
- Stage 5 — Evaluation
- Stage 6 — Integrated synthesis

GitHub is the course source of truth. The live course state and continuity protocol are stored in:

- `00-course/COURSE-STATE.md`
- `00-course/COURSE-MANAGEMENT.md`
- `00-course/MASTER-KNOWLEDGE-GRAPH.md`
- `00-course/progress.md`

## Structure

- `00-course/` learning plan, state, knowledge graph, and study process
